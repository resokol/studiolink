# Гостевой вход и инвайты — 26 сентября 2026

Гостевая страница `/room` теперь всегда показывает два поля: название комнаты
и пароль. Ошибка пароля возвращает `401`, удаляет старую cookie авторизации и
не позволяет получить LiveKit-токен. Комната без пароля принимает только пустое
значение пароля; произвольный введённый пароль отклоняется.

Студийная cookie больше не даёт гостю обходить пароль комнаты. Это важно, если
студия и гость открыты в одном браузере или на одном компьютере.

В студии кнопка `гости могут слушать и видеть только студию` включает режим
просмотра только студии. Кнопка `Скопировать инвайт для гостя` создаёт
подписанную ссылку на 30 дней. Инвайт привязан к комнате и текущему хэшу её
пароля: после изменения пароля старая ссылка перестаёт работать. Переход по
инвайту сразу пропускает форму пароля, но гость всё равно вводит имя, выбирает
камеру, микрофон и качество перед входом.

Проверены подмена ссылки, истёкший срок, перенос инвайта в другую комнату,
viewer-ссылка выхода, смена пароля, неверный пароль после правильного входа,
пустой пароль открытой комнаты и отсутствие доступа к API инвайтов без студии.
